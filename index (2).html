// 03 — Technical Breakdown
01

Octave Perlin Noise

Multi-layered noise using Mathf.PerlinNoise with configurable octaves, persistence, and lacunarity. Each octave adds finer detail while preserving macro terrain shapes.

02

Height-Based Biome System

Terrain layers assigned by normalised height thresholds. Each TerrainLayer defines a cutoff and color — fully designer-configurable with live preview, no code edits required.

03

Procedural Mesh Generation

Runtime-generated mesh with vertices displaced along Y via the noise map. A MeshCollider is built from the same data — physics accuracy always matches visuals.

04

Seed & Offset System

Every generation driven by a seed and offset vector — reproducible worlds and infinite panning. Same seed always yields identical terrain, critical for save systems.

05

Prop Spawning

A SpawnProps(biome) method distributes objects using the noise map as a probability field. Props placed by biome type and height — no manual placement required.

06

Multi-Mode Display

Three draw modes: NoiseMap (debug heightmap), ColourMap (flat biome view), and Mesh (full 3D). Switchable live — built for fast design iteration.

Designer-Friendly
Parameter Exposure

All generation parameters are exposed in the Unity Inspector — no code edits needed to iterate on terrain shape or biomes. Tools should empower designers, not block them.

Noise.cs — GenerateNoiseMap()
// Multi-octave Perlin noise with normalized output
for (int y = 0; y < mapHeight; y++) {
  for (int x = 0; x < mapWidth; x++) {
    float amplitude = 1;
    float frequency = 1;
    float noiseHeight = 0;

    for (int i = 0; i < octaves; i++) {
      float sampleX = (x - halfWidth) / scale * frequency + octaveOffsets[i].x;
      float sampleY = (y - halfHeight) / scale * frequency + octaveOffsets[i].y;

      float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2 - 1;
      noiseHeight += perlinValue * amplitude;

      amplitude *= persistance;
      frequency *= lacunarity;
    }
    noiseMap[x, y] = noiseHeight;
  }
}
// Normalize to [0,1] range
noiseMap[x, y] = Mathf.InverseLerp(minNoiseHeight, maxNoiseHeight, noiseMap[x, y]);
